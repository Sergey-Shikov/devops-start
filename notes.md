# Шпаргалка DevOps — мои команды

## 🐧 Linux: навигация и файлы

| Команда | Что делает |
|---|---|
| `pwd` | Показать, где я (print working directory) |
| `ls` | Список файлов в текущей папке |
| `ls -a` | Показать скрытые файлы (начинающиеся с `.`) |
| `cd ~/папка` | Перейти в папку |
| `cd ~` | Перейти в домашнюю папку |
| `cd ..` | Перейти на уровень выше |
| `mkdir имя` | Создать папку |
| `touch файл.txt` | Создать пустой файл |
| `mv старое новое` | Переименовать или переместить |
| `rm файл` | Удалить файл (без корзины!) |
| `rm -r папка` | Удалить папку со всем содержимым |
| `cat файл` | Показать содержимое файла |
| `nano файл` | Открыть редактор (Ctrl+O — сохранить, Ctrl+X — выйти) |
| `echo "текст" > файл` | Записать текст в файл (затирает) |
| `echo "текст" >> файл` | Дописать текст в конец файла |

## 🐧 Linux: права и установка

| Команда | Что делает |
|---|---|
| `sudo команда` | Выполнить от имени администратора |
| `sudo apt update` | Обновить список доступных пакетов |
| `sudo apt install пакет -y` | Установить программу |
| `sudo apt remove пакет` | Удалить программу |
| `sudo service docker start` | Запустить службу Docker |

## 🐧 Linux: процессы

| Команда | Что делает |
|---|---|
| `htop` | Монитор процессов (выход — `q`) |
| `ps aux` | Список всех процессов |
| `ps aux \| grep имя` | Найти процесс по имени |
| `sleep 300 &` | Запустить команду в фоне на 5 минут |
| `kill PID` | Завершить процесс по номеру |

## 🐧 Linux: поиск и конвейеры

| Команда | Что делает |
|---|---|
| `grep "слово" файл` | Найти строки со словом |
| `grep -i "слово" файл` | То же, без учёта регистра |
| `команда \| grep слово` | Передать вывод команды в grep |
| `команда > файл` | Записать вывод в файл (затирает) |
| `команда >> файл` | Дописать вывод в файл |

## 🌐 Сети

| Команда | Что делает |
|---|---|
| `curl ifconfig.me` | Мой внешний IP |
| `ping ya.ru` | Проверить связь (остановить — Ctrl+C) |
| `ping 127.0.0.1` | Проверить loopback (сам себя) |

## 🔑 Git: настройка (один раз)

| Команда | Что делает |
|---|---|
| `git config --global user.name "Имя"` | Задать имя автора коммитов |
| `git config --global user.email "почта"` | Задать почту автора |
| `git config --global --list` | Проверить настройки |
| `git config --global init.defaultBranch main` | Новая ветка = main |
| `git config --global credential.helper store` | Запомнить токен |

## 🔑 Git: рабочий цикл

| Команда | Что делает |
|---|---|
| `git init` | Создать репозиторий в папке |
| `git status` | Что происходит (красные = не добавлены, зелёные = готовы) |
| `git add .` | Добавить все файлы в staging |
| `git commit -m "сообщение"` | Зафиксировать снимок |
| `git push` | Отправить на GitHub |
| `git log --oneline` | История коммитов кратко |
| `git branch` | Показать ветки |
| `git branch -m main` | Переименовать текущую ветку в main |
| `git remote add origin URL` | Связать с GitHub |
| `git remote -v` | Проверить связь |
| `git push -u origin main` | Первый push с привязкой |

## 🔑 Git: работа с GitHub

- **Токен** создаётся на https://github.com/settings/tokens
  - Note: любое имя (уникальное)
  - Expiration: 90 days
  - Scopes: только галочка `repo`
- **Копировать токен** нужно **иконкой копирования**, не выделением
- **При push:** Username — логин GitHub, Password — токен (не пароль!)
- **Токен показывается один раз** — сохраните сразу

## 🐳 Docker: установка и запуск

| Команда | Что делает |
|---|---|
| `docker --version` | Проверить версию |
| `sudo service docker start` | Запустить Docker (в WSL вручную) |

## 🐳 Docker: контейнеры

| Команда | Что делает |
|---|---|
| `docker run hello-world` | Первый контейнер |
| `docker run -d -p 8080:80 nginx` | Запустить nginx в фоне, порт 8080→80 |
| `docker ps` | Запущенные контейнеры |
| `docker ps -a` | Все контейнеры (включая остановленные) |
| `docker logs ID` | Логи контейнера |
| `docker stop ID` | Остановить |
| `docker rm ID` | Удалить |
| `docker images` | Список скачанных образов |

**Разбор `docker run -d -p 8080:80 nginx`:**
- `-d` — в фоне (detached)
- `-p 8080:80` — порт 8080 на компе → порт 80 внутри контейнера
- `nginx` — имя образа

## 💡 Полезные мелочи

- **`Ctrl+C`** — если что-то зависло или вы застряли в `>` (продолжение строки)
- **`clear`** — очистить экран
- **`history`** — все команды за сессию
- **`man команда`** — справка (выход — `q`)
- **`explorer.exe .`** — открыть текущую папку в Проводнике Windows

## 📌 Основные правила

1. **Молчание = успех.** Если команда ничего не вывела — всё ок.
2. **Пароль не отображается** при вводе (sudo, токен) — это норма.
3. **`>` затирает, `>>` дописывает.** Разница критична.
4. **`rm` в Linux нет корзины.** Удалённое не восстановить.
5. **Коммит = снимок.** Можно вернуться к любой точке.
6. **Синтаксис не надо заучивать** — надо понимать смысл и уметь гуглить.
